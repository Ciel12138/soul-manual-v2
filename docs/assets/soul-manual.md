#### 单卡详情

**且听风吟（容）**
- 出处：村上春树同名小说 / 朴树同名歌
- 场景：对话、赴约的开场；对方说话时自己冒出想反驳、想解释、想防御的念头
- 开关：肩膀下沉一次，缓慢呼气，想象站在风里——念头像风，来了就让它们过去
- 红线：只容不动会滑成被动；听完记得走第二步

**镜湖（明）**
- 出处：意象自铸；底子出自《庄子·应帝王》——"至人之用心若镜，不将不迎，应而不藏，故能胜物而不伤"
- 场景：委屈、愤怒、想战或逃的情绪起来时；做重要判断前；感觉脑子被"因果故事"带跑时
- 开关：闭眼，用 3 次呼吸让心里的波纹平下来，再睁眼，问自己一句——"湖面现在照出的是什么？"
- 红线：镜湖只负责照见，不负责行动。看清之后必须接一句："那然后呢？"

**无量空处（威）**
- 出处：《咒术回战》五条悟领域展开——取"主权"义，弃"压制"义
- 场景：(a) 高压要站住：考试开场、被当众施压、需要镇场；(b) 快被冲垮时设闸
- 开关：双脚踩实地面，脊柱挺直，心里一句"此刻，什么能进来由我说了算"，注意力收回自己的领域边界
- 红线：对外不对人；站发动者位不站受困者位；用完即收，主动切回

#### 与承接成长的关系

且听风吟=先接住对方，镜湖=看清楚再回应，无量空处=我也有不被冲垮的边界。**没有第三档的温柔是讨好，有了它才叫承接。**

### 3.3 归档体系

#### 收藏夹

**No.57 · 因果律既是武器又是盾牌（Fate/stay night）**
- 素材：FSN UBW 线，炽天覆七重圆环（Rho Aias）vs 盖伯尔加（Gáe Bolg）；三层神话考据——伊利亚特（埃阿斯七层牛皮盾挡赫克托耳投枪，穿六停七）→ FSN 同构复刻 → 冈格尼尔/大神宣言为型月设定原型
- 拆解：武器面成立（追因=打在杠杆点；22:30 修行任务本质是因果工程；NVC 即因果律应用）。盾面有条件成立（承接=把对方攻击翻译成因果现象，攻击即非针对"我"）
- 不迎合注：人手中的"因果律"多为**因果故事**（休谟：只观察到恒常联结，未观察到因果本身）；错的因果图照样有武器盾牌的手感，但护住不该护的东西
- 关键修正：因果版穿刺死棘之枪**无盾可挡**——唯一对抗是"扭转命运的强运"，即**不承认被宣布的果**
- 用法：现实的因果枪=自我实现预言与他人判词；先宣布果、让你自己补齐因。解法不是加厚盾，是动起来改写已宣布的结局
